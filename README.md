# سند (Sanad) — نظام الموارد البشرية

نظام موارد بشرية لشركة واحدة في الكويت:
- تبصيم الحضور والانصراف ببصمة الجوال (الوجه أو الإصبع) مع صورة للمراجعة، والتحقق من الموقع.
- الإجازات والطلبات، والجزاءات، وقوائم المكافآت الشهرية.
- لوحة للموظف، ووحدة طوارئ لإخلاء المباني.

- المتطلبات: [docs/PRD.md](docs/PRD.md)
- خطة التنفيذ ومراحلها: [docs/PLAN.md](docs/PLAN.md)

## هيكل المستودع

| المجلد | المحتوى |
|---|---|
| `apps/mobile` | تطبيق الجوال لـ Android وiOS (Expo / React Native) |
| `apps/mobile/modules/sanad-device-key` | جزء أصلي صغير: مفتاح توقيع التبصيم داخل شريحة الأمان في الجوال |
| `apps/admin` | لوحة الإدارة على الويب (Next.js) |
| `supabase/` | قاعدة البيانات (الجداول والصلاحيات) ودوال السيرفر (`punch` و`device-key` وغيرها) |
| `tools/face-model` | نموذج الوجه المستخدم في تسجيل الوجه من لوحة الإدارة |
| `docs/` | الوثائق |

## المتطلبات على الجهاز

- **Node.js** الإصدار 24 أو أحدث
- **Android Studio** (أو Android SDK وJava 17): لبناء نسخة أندرويد وتشغيل المحاكي
- **تطبيق Expo Go** على الجوال: لتجربة الشاشات بسرعة فقط (بدون توقيع التبصيم)

## تثبيت التطبيق على الجوال (أندرويد)

مع كل تحديث على `main` يبني GitHub ملف التثبيت تلقائياً:
1. افتح صفحة **Actions** في المستودع، ثم آخر تشغيل ناجح لـ `main`.
2. من قسم **Artifacts** نزّل `sanad-android-apk`، وفك الملف المضغوط.
3. ثبّت `app-release.apk` على الجوال.

## التشغيل للتطوير

### لوحة الإدارة
```bash
cd apps/admin
npm install
npm run dev
```
ثم افتح http://localhost:3000

### تطبيق الجوال
```bash
cd apps/mobile
npm install
npm start
```
- للتجربة السريعة: امسح رمز QR بتطبيق Expo Go.
- لتجربة التبصيم الموقّع (يحتاج الجزء الأصلي): `npx expo run:android` على جوال موصول أو محاكي.

التطبيق يتصل بمشروع Supabase مباشرة بالمفتاح العام فقط. لتغيير المشروع استخدم `EXPO_PUBLIC_SUPABASE_URL` و`EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY`، ولا تضع أي مفتاح سري في التطبيق.

## الإعدادات

انسخ `.env.example` إلى `apps/admin/.env.local` وضع فيه المفاتيح. **لا ترفع ملفات المفاتيح إلى GitHub أبداً.**

## البيانات الوهمية واختبارات الصلاحيات

تحتاج المفتاح السري في `apps/admin/.env.local`.

```bash
cd supabase/scripts
npm install
npm run demo:seed
npm run test:rls
npm run demo:reset
```

- `demo:seed`: ينشئ 3,500 موظف وهمي وحسابات دخول تجريبية، وكلمات المرور تُحفظ في `supabase/scripts/.demo-credentials.json` (لا يُرفع إلى GitHub).
- `test:rls`: يختبر صلاحيات كل دور.
- `demo:reset`: يحذف البيانات الوهمية، ويُبقي حساب مدير النظام 735043.

## الاختبارات

```bash
# لوحة الإدارة
cd apps/admin
npm test          # اختبارات قواعد الإدخال
npm run test:e2e  # اختبارات المتصفح (Playwright)، تحتاج المفتاح السري

# تطبيق الجوال
cd apps/mobile
npm run typecheck
npm test

# دوال السيرفر (التبصيم وتسجيل مفتاح الجوال) — من جذر المستودع
node --import ./supabase/functions/punch/test/register.mjs --test 'supabase/functions/punch/test/*.test.mjs'
```

اختبارات المتصفح تنشئ حسابات مؤقتة (799901–799903) بكلمات مرور عشوائية لا تُعرض، وتحذفها مع كل ما أنشأته عند الانتهاء.

## الفحص الآلي

مع كل Pull Request وكل تحديث على `main` يشغّل GitHub الفحوصات التالية:
- لوحة الإدارة: فحص الكود، واختبارات قواعد الإدخال، والبناء.
- تطبيق الجوال: فحص الأنواع، والاختبارات، وتجميع نسخة أندرويد.
- بناء ملف التثبيت `sanad-android-apk`.
- اختبارات دوال السيرفر (`punch` و`device-key`).
- البحث عن أي مفاتيح سرية داخل المستودع.
