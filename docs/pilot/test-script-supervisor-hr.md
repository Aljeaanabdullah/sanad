# سكربت التجربة — المشرف والموارد البشرية ومدير النظام (لوحة الويب)

| البند | القيمة |
|---|---|
| لمن | المشرف، وموظف الموارد البشرية (HR)، ومدير النظام |
| الجهاز | كمبيوتر بمتصفح حديث (Chrome أو Edge)، ورابط لوحة الويب المنشور. المشرف وHR يقدرون يستخدمون الجوال أيضاً للموافقات |

- «بعد دمج المرحلة X» = الخطوة تشتغل بعد دمج تلك المرحلة. إذا ما اندمجت بعد، اكتب «تخطّي».
