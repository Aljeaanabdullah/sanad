# سكربت التجربة — الموظف (تطبيق الجوال)

| البند | القيمة |
|---|---|
| لمن | موظف التجربة (بدون خبرة تقنية) |
| الجهاز | جوالك الشخصي (Android أولاً) وعليه تطبيق سَنَد الجديد |
| المدة | الجزء أ: 15 دقيقة في اليوم 0. الباقي خلال أيام التجربة |
| المرجع | [خطة التجربة](pilot-checklist.md) |

**طريقة الاستخدام:**
- امشِ على الخطوات بالترتيب، واكتب ✅ إذا صارت النتيجة المتوقعة، أو ❌ إذا صار شي ثاني.
- عند ❌: صوّر الشاشة، واكتب الوقت والمكان في «ملاحظات»، وأرسل البلاغ للمنسّق.
- «بعد دمج المرحلة X» = الخطوة تشتغل بعد ما تندمج تلك المرحلة. إذا ما اندمجت بعد، اكتب «تخطّي».

## أ. التجهيز (اليوم 0، مع المنسّق)

| # | الخطوة | النتيجة المتوقعة | ✅ / ❌ | ملاحظات |
|---|---|---|---|---|
| أ1 | افتح تطبيق سَنَد لأول مرة | شاشة البداية بشعار سَنَد، ثم اختيار اللغة والمظهر | | |
| أ2 | اختر «العربية» والمظهر اللي يناسبك | الواجهة بالعربي ومن اليمين لليسار | | |
| أ3 | اكتب رقم ملفك وكلمة المرور اللي استلمتها، واضغط دخول | تفتح شاشة «تغيير كلمة المرور» | | |
| أ4 | اكتب كلمة مرور جديدة (8 أحرف على الأقل، فيها حرف ورقم، بدون رقم ملفك) مرتين | تُقبل وتنتقل للخطوة التالية | | |
| أ5 | جرّب كلمة مرور فيها رقم ملفك | رسالة: «لا تستخدم رقم ملفك داخل كلمة المرور.» | | |
| أ6 | أكّد ربط هذا الجوال بحسابك | يرتبط الجوال | | |
| أ7 | اقرأ نص الموافقة واضغط «أوافق» | تُحفظ الموافقة وتفتح الرئيسية | | |
| أ8 | إذا طلب Face ID أو البصمة لتسجيل مفتاح التبصيم، سوّها | يقبل بدون رسالة خطأ | | |
| أ9 | اسمح للتطبيق بالموقع والكاميرا عند الطلب | ما يظهر «الإذن مقفل» | | |
| أ10 | اسمح بالإشعارات — **بعد دمج المرحلة 9** | يظهر طلب إذن الإشعارات وتوافق عليه | | |
| أ11 | شوف الرئيسية | اسمك ورقم ملفك، وبطاقة «حضور اليوم»، وزر «بصمة الحضور» وزر «بصمة الانصراف»، وملخص الفترة | | |
| أ12 | تنقّل في الشريط السفلي: الرئيسية، الطلبات، التقارير، المزيد | كل شاشة تفتح بدون خطأ | | |
| أ13 | من «المزيد» غيّر اللغة للإنجليزي ثم رجّعها | الواجهة تنقلب LTR ثم ترجع RTL | | |
| أ14 | غيّر المظهر نهاري / ليلي | الألوان كحلي وذهبي واضحة في الاثنين | | |

## ب. التبصيم (كل يوم)

| # | الخطوة | النتيجة المتوقعة | ✅ / ❌ | ملاحظات |
|---|---|---|---|---|
| ب1 | وأنت **داخل** الموقع، اضغط «بصمة الحضور» | يفحص الجوال، ثم يلتقط صورة، ثم يطلب Face ID أو البصمة | | |
| ب2 | سوّ Face ID أو البصمة | «تم تسجيل الحضور بنجاح» مع التاريخ والوقت. **اكتب كم ثانية أخذت** | | |
| ب3 | ارجع للرئيسية | «حضور اليوم» يبين وقت دخولك | | |
| ب4 | آخر الدوام وأنت داخل الموقع، اضغط «بصمة الانصراف» | «تم تسجيل الانصراف بنجاح» | | |
| ب5 | من «التقارير» افتح تقويم الحضور | اليوم عليه نقطة «حضور» (أو «تأخير» إذا تأخرت)، ووقت الدخول والخروج صحيح | | |
| ب6 | اضغط «بصمة الحضور» مرة ثانية بعد ما بصمت انصراف | رسالة: «سجّلت انصرافك من هذه الوردية.» | | |

## ج. حالات الرفض (مرة وحدة لكل حالة، حسب جدول المنسّق)

| # | الخطوة | النتيجة المتوقعة | ✅ / ❌ | ملاحظات |
|---|---|---|---|---|
| ج1 | من **خارج** الموقع (مثلاً البيت)، اضغط «بصمة الحضور» | «أنت خارج نطاق موقع العمل.» | | |
| ج2 | عند **حافة** الموقع (البوابة أو المواقف)، بصمة حضور | **تُقبل** إذا كنت داخل الموقع. إذا رُفضت وأنت داخل، اكتب مكانك بالضبط (رفض كاذب) | | |
| ج3 | اطفِ الموقع (GPS) من إعدادات الجوال، وجرّب | رسالة تطلب تفعيل الموقع | | |
| ج4 | اطفِ الإنترنت، وجرّب | ما تنقبل البصمة، ورسالة عن الاتصال | | |
| ج5 | اطلب من زميل يسوي Face ID / البصمة على جوالك | ما تنرسل البصمة: «ما تم التحقق بـ Face ID أو البصمة.» | | |
| ج6 | ادخل بحسابك من **جوال ثاني** | «حسابك مرتبط بجوال آخر» | | |
| ج7 | شغّل VPN وبصمة حضور داخل الموقع | **تُقبل** (VPN يُسجَّل فقط) | | |
| ج8 | (متطوع واحد فقط، Android، مع المنسّق) شغّل تطبيق موقع وهمي وجرّب | «تم اكتشاف تطبيق لتغيير الموقع. أوقفه ثم حاول مرة أخرى.» | | |
| ج9 | بعد 5 محاولات فاشلة متتالية | «محاولات فاشلة كثيرة…» وانتظار 5 دقائق | | |

## و. لوحتي واسأل سند

| # | الخطوة | النتيجة المتوقعة | ✅ / ❌ | ملاحظات |
|---|---|---|---|---|
| و1 | «التقارير» ← «لوحتي» | أرقام الفترة (21 إلى 20): الحضور، الغياب، التأخير، الإجازات، وحالة المكافأة (تقديرية قبل القفل) | | |
| و2 | قارن أرقام لوحتي بتقويم الحضور | نفس الأرقام | | |

| و5 | اسأل عن زميل بالاسم أو رقم الملف | ما يعطيك أي معلومة عن غيرك | | |
| و6 | تأكد من عدد الأسئلة الباقية اليوم | «باقي لك {n} سؤال اليوم.» (الحد 20 في اليوم) | | |

## ح. أسئلتك بعد التجربة (اكتب بكلماتك)

1. كم مرة رُفضت بصمتك وأنت داخل الموقع؟
2. هل كانت البصمة سريعة؟ (أقل من 10 ثوانٍ؟)
3. أي رسالة ما فهمتها؟
4. هل وصلتك الإشعارات في وقتها؟
5. أي شي ثاني تبي تقوله؟
